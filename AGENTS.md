# Conventions — arpeiks/skillz

> Engineering conventions for all projects. Source of truth:
> https://github.com/arpeiks/skillz — do not edit this file in a project;
> re-sync it instead.

Version: 0.6.1 · Updated: 2026-09-08

## Always apply

These are non-negotiable and apply to every task, with no need to fetch
anything further.

### Git

- Commit **only what is already staged**. Never `git add -A`, `git add .`, or
  `git commit -a` — unstaged changes are unstaged on purpose.
- Keep commit messages short.
- Never add a co-author trailer.
- Never rewrite pushed history — no `reset`, `amend`, or force push. Fix forward.

### Code

- Use **Bun** for everything — `bun install`, `bun add`, `bun run`, `bunx`.
  Never npm, yarn, or pnpm. Docs show the npm form; translate it, don't paste it.
- New frontend projects: TanStack Start + Router + Query, Tailwind 4.
- **coss ui** is the default component library for React. When adding one,
  also install its skills into the project: `bunx skills add cosscom/coss`.
- File names are lowercase **kebab-case**.
- Components are **PascalCase, named for what they are** — `About`, not
  `LandingAbout`. Prefix only where the distinction is required: a collision,
  or a bare name too generic to mean anything (`RouterComponent`).
- Prefer `export const Name = () => {}` over `export function Name() {}`.
  Default exports only where a library demands one. Arrow functions are not
  hoisted — declare a component before anything references it.
- A single-expression function gets a concise one-line body —
  `const Home = () => null`, never a block wrapping a lone `return`.
- Import internals via the `#/*` subpath alias, never deep relative paths.
- **Never format by hand.** Run the project's `format` script.
- Imports are sorted **by line length, shortest first**, as one block with no
  blank lines between them. Side-effect imports keep their position.
